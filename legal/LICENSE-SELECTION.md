# License selection

The project license is intentionally not frozen yet.

Before selecting a license, the project should decide:

- whether the core is permissive or copyleft;
- how integrations with external projects are licensed;
- how third-party code is attributed;
- how proprietary NVIDIA components are handled;
- whether research assets/models require separate terms.

Until this document is replaced by an approved project license, contributors must preserve the license terms of all third-party dependencies and must not add proprietary binaries without appropriate rights.
